BAB 1: PENGOLAH KATA (WORD PROCESSOR)

Aplikasi pengolah kata (word processor) adalah perangkat lunak yang dirancang khusus untuk membuat, menyunting, memformat, menyimpan, dan mencetak dokumen berbasis teks.

1. Pengertian dan Konsep Pengolah Kata

  • Pada Komputer / Laptop: Merupakan perangkat lunak berbasis desktop yang menawarkan fitur penyuntingan tingkat lanjut, tata letak dokumen kompleks, pembuatan laporan ilmiah, tata letak halaman presisi, hingga pengintegrasian data berskala besar.
  • Pada HP / Smartphone / Tablet: Merupakan aplikasi seluler yang dioptimalkan untuk navigasi layar sentuh, pembuatan dokumen cepat, penyuntingan darurat saat bepergian (on-the-go), serta sinkronisasi otomatis ke media penyimpanan awan (cloud storage).

2. Jenis-Jenis Aplikasi Pengolah Kata

  • Pada Komputer / Laptop: Microsoft Word, Google Docs (berbasis peramban), LibreOffice Writer, dan WPS Office Desktop.
  • Pada HP / Smartphone / Tablet: Microsoft Word Mobile, Google Docs Mobile App, dan WPS Office Mobile.

3. Ekstensi dan Format File

  • Pada Komputer / Laptop: Format standar utama adalah .docx, .doc, .rtf, serta .pdf untuk dokumen siap cetak.
  • Pada HP / Smartphone / Tablet: Mendukung format .docx dan .pdf, serta penyimpanan draf otomatis berbasis awan.

4. Fitur-Fitur Penyuntingan dan Tata Letak Teks

  • Perataan Teks (Alignment): Align Left (Rata Kiri), Center (Rata Tengah), Align Right (Rata Kanan), dan Justify (Rata Kiri-Kanan).
  • Drop Cap:
    • Komputer/Laptop: Memperbesar huruf awal paragraf memakan 2-3 baris ke bawah.
    • HP/Tablet: Diatur melalui gaya tampilan atau template dokumen seluler.
  • Mail Merge (Surat Massal):
    • Komputer/Laptop: Menghubungkan master surat ke database/tabel Excel untuk mencetak surat masal otomatis.
    • HP/Tablet: Sangat terbatas, umumnya diakses melalui mode web desktop browser tablet.
  • Page Break: Perintah memutus halaman baru tanpa menekan tombol enter berulang kali (di HP diakses via menu Insert).
  • Footnote (Catatan Kaki): Keterangan rujukan ilmiah di dasar halaman dokumen.

BAB 2: SISTEM KOMPUTER

Sistem Komputer adalah kumpulan perangkat keras, perangkat lunak, dan manusia yang saling berinteraksi untuk melakukan siklus pengolahan data menjadi informasi.

1. Informasi Dasar dan Konsep Komputasi

  • Komputer / Laptop: Sistem komputasi daya tinggi dengan fleksibilitas modular, penanganan pekerjaan berat, dan multitasking tingkat tinggi.
  • HP / Smartphone / Tablet: Sistem komputasi bergerak berdaya rendah, berukuran ringkas, baterai terintegrasi, dan mengintegrasikan seluruh sirkuit ke dalam satu cip tunggal.

2. Siklus Pengolahan Data

Input (Masukan) ➔ Process (Pemrosesan) ➔ Output (Keluaran) ➔ Storage (Penyimpanan)

3. Perangkat Keras (Hardware)

A. Perangkat Masukan (Input Device)

  • Komputer / Laptop: Keyboard, Mouse/Touchpad, Scanner, dan Mikrofon Desktop.
  • HP / Smartphone / Tablet: Layar Sentuh (Touchscreen), Kamera Depan/Belakang, Sensor Biometrik (Fingerprint/Face Unlock), Sensor Gerak (Accelerometer, Gyroscope, GPS), dan Mikrofon Seluler.

B. Perangkat Pemroses (Processing Device)

  • Komputer / Laptop: CPU (Central Processing Unit) terpisah, GPU (Graphics Processing Unit) tersendiri, dan Motherboard besar.
  • HP / Smartphone / Tablet: SoC (System on a Chip) yang menggabungkan CPU, GPU, Modem Seluler, dan NPU (AI) dalam satu cip silikon tunggal.

C. Perangkat Penyimpanan (Storage Device)

  • Komputer / Laptop: RAM volatile, ROM/BIOS, dan Harddisk/SSD sekunder berkapasitas besar.
  • HP / Smartphone / Tablet: RAM seluler berdaya hemat, Memori Internal (eMMC/UFS), serta slot Memori Eksternal (MicroSD).

D. Perangkat Keluaran (Output Device)

  • Komputer / Laptop: Monitor, Printer/Plotter, dan Speaker/Headphone.
  • HP / Smartphone / Tablet: Layar Display (OLED/AMOLED/LCD), Speaker Internal, dan Vibration Motor (Haptic Engine).

4. Perangkat Lunak (Software)

A. Sistem Operasi (Operating System / OS)

  • Komputer / Laptop: Microsoft Windows, macOS, dan Linux.
  • HP / Smartphone / Tablet: Android dan iOS / iPadOS.

B. Perangkat Lunak Aplikasi (Application Software)

  • Komputer / Laptop: Microsoft Office, Adobe Photoshop, Google Chrome (versi desktop berfitur lengkap).
  • HP / Smartphone / Tablet: WhatsApp, Instagram, TikTok, Mobile Banking, dan Browser Mobile.

C. Perangkat Lunak Utilitas (Utility Software)

  • Komputer / Laptop: Antivirus Desktop (Smadav/Avast), WinRAR, Disk Cleaner.
  • HP / Smartphone / Tablet: Manajer Penyimpanan bawaan (Cache Cleaner), Battery Saver, dan Find My Device.
