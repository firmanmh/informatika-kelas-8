BAB 1. APLIKASI PENGOLAH KATA & MANAJEMEN CLIPBOARD

Aplikasi Pengolah Kata (Word Processor) adalah perangkat lunak yang dirancang untuk membuat, menyunting, memformat, menyimpan, hingga mencetak dokumen berbasis teks (seperti surat, laporan praktikum, dan makalah).

A. Jenis-Jenis Aplikasi Pengolah Kata

Kategori Aplikasi Cara Kerja & Penyimpanan Contoh Perangkat Lunak
Berbasis Desktop (Offline) Diinstal langsung di komputer/laptop, berjalan tanpa koneksi internet, dokumen tersimpan di penyimpanan lokal (HDD/SSD). Microsoft Word, LibreOffice Writer, WPS Office Writer, Apple Pages
Berbasis Cloud (Online) Dijalankan melalui web browser dengan koneksi internet, tersimpan otomatis di awan, mendukung kolaborasi bersamaan. Google Docs, Microsoft Word Online (Office 365)

B. Tampilan Utama & Bagian Antarmuka Pengolah Kata (Klik Nomor Bagian!)

Kenali 6 bagian utama jendela aplikasi pengolah kata pada simulasi visual di bawah ini. Sentuh atau klik lingkaran nomor [1] hingga [6] pada gambar untuk melihat fungsi masing-masing bagian!

SIMULASI INTERAKTIF ANTARMUKA PENGOLAH KATA (KLIK PIN NOMOR 1–6)
[1] Quick Access Toolbar (QAT): Bilah pintasan cepat di pojok kiri atas berisi tombol perintah yang paling sering dipakai, seperti Save (Simpan), Undo (Batalkan), dan Redo (Ulangi).

C. Alur Kerja Pembuatan Dokumen & Tombol Perintah Esensial

Ctrl + N Membuat dokumen baru (New)
Ctrl + S Menyimpan dokumen (Save)
Ctrl + Z Membatalkan langkah terakhir (Undo)
Ctrl + Y Mengulangi langkah dibatalkan (Redo)
Ctrl + H Mencari & mengganti kata (Replace)
Ctrl + B/I/U Tebal / Miring / Garis Bawah

D. Simulasi Bergerak: Fitur Kombinasi Copy, Cut, dan Paste

Perintah Copy (Ctrl+C) menggandakan data ke memori sementara bernama Clipboard (RAM) tanpa menghapus data asli, sedangkan Cut (Ctrl+X) memindahkan data ke Clipboard sehingga data asli terhapus setelah ditempel dengan Paste (Ctrl+V).

SIMULASI INTERAKTIF CLIPBOARD (COBA KLIK COPY ATAU CUT LALU PASTE)
Status: Silakan klik tombol Copy atau Cut terlebih dahulu.
Tips Penting Penggunaan Save vs Save As:

• Save (Ctrl + S): Menyimpan pembaruan isi pada file lama tanpa mengubah nama maupun lokasi foldernya.

• Save As (F12): Menyimpan dokumen sebagai salinan file baru dengan nama baru, lokasi folder baru, atau format ekstensi baru (misalnya ekspor ke .pdf).

BAB 2. MANAJEMEN FILE, FOLDER & EKSTENSI BERKAS

File (Berkas) adalah satuan data atau informasi digital yang tersimpan di media penyimpanan komputer/HP (seperti dokumen tugas, foto, lagu, atau video). Sementara itu, Folder (Direktori) adalah wadah virtual yang digunakan untuk mengelompokkan berbagai file maupun subfolder agar tertata rapi, terstruktur, dan mudah ditemukan kembali.

A. Manajemen File & Folder pada Laptop, HP, dan Cloud Storage

Platform / Media Aplikasi Bawaan & Pihak Ketiga Langkah Membuat Folder Baru Karakteristik Penyimpanan
Laptop / PC
(Windows / macOS)		 Windows File Explorer, Finder (macOS), Total Commander Klik kanan di area kosong → New → Folder (atau tekan Ctrl + Shift + N) → ketik nama → Enter. Tersimpan lokal di Harddisk (HDD) atau SSD; akses sangat cepat tanpa butuh internet.
Smartphone (HP)
(Android / iOS)		 Files by Google, File Manager bawaan, File Apple (iOS), ZArchiver Buka File Manager → masuk ke Penyimpanan Internal → ketuk ikon titik tiga / tambah (+) → pilih Buat Folder Baru. Tersimpan di memori internal HP atau kartu memori eksternal (MicroSD).
Cloud Storage
(Penyimpanan Awan)		 Google Drive, Microsoft OneDrive, Apple iCloud, Dropbox, TeraBox Buka layanan cloud (misal Google Drive) → klik tombol + Baru (New) → pilih Folder baru → ketik nama → Buat. Tersimpan di server internet; dapat diakses dari HP maupun laptop kapan saja & mudah dibagikan lewat tautan.

C. Ekstensi File Berdasarkan Kategori dan Aplikasi Pembukanya

Ekstensi file (file extension) adalah akhiran berupa 3 hingga 4 huruf di belakang tanda titik (.) pada nama file (contoh: Tugas_IPA.docx). Ekstensi berfungsi memberi tahu sistem operasi jenis isi data di dalam file tersebut dan aplikasi apa yang tepat untuk membukanya.

Kategori File Contoh Ekstensi Keterangan Format Aplikasi Pembuka / Pengolah
Dokumen & Data .docx, .pdf, .xlsx, .pptx, .txt Dokumen teks berformat, dokumen portabel tetap, tabel angka, presentasi, dan teks polos. Microsoft Office (Word/Excel/PPT), Google Docs/Sheets/Slides, Adobe Reader, Notepad
Gambar / Grafis .jpg / .jpeg, .png, .gif, .svg Foto digital terkompresi, gambar latar transparan, animasi pendek, dan gambar vektor. Photos, Galeri HP, Paint, Canva, Adobe Photoshop, Web Browser
Audio (Suara) .mp3, .wav, .m4a, .ogg File musik/rekaman suara terkompresi ukuran kecil (.mp3) maupun kualitas studio (.wav). VLC Media Player, Windows Media Player, Pemutar Musik HP, Audacity
Video .mp4, .mkv, .avi, .mov Berkas gambar bergerak beserta suara dengan berbagai tingkat resolusi. VLC Media Player, MX Player, Pemutar Video HP, CapCut
Arsip / Kompresi .zip, .rar, .7z Menggabungkan banyak file/folder menjadi satu paket arsip dan memperkecil ukuran file. WinRAR, 7-Zip, Windows File Explorer, ZArchiver (Android)
Aplikasi / Sistem .exe, .apk, .html Program instalasi Windows (.exe), paket aplikasi Android (.apk), dan halaman web (.html). Sistem Operasi Windows, Android Installer, Google Chrome / Edge
Peringatan Penting tentang Pengubahan Ekstensi Manual:

Mengubah nama ekstensi file secara paksa lewat fitur Rename (misalnya mengganti Video_Wisata.mp4 menjadi Video_Wisata.pdf) tidak mengubah format isi data biner di dalamnya. Akibatnya, file tersebut akan gagal dibuka (corrupted/unreadable). Untuk mengubah format secara sah, gunakan fitur Save As / Export atau aplikasi konverter.

BAB 3. SISTEM KOMPUTER & ALUR OPERASI CPU (MACHINE CYCLE)

Sistem Komputer adalah jaringan elemen-elemen yang saling berhubungan dan bekerja sama untuk menerima masukan (input), memproses data (process), menyimpan (storage), serta menghasilkan keluaran informasi (output). Agar komputer dapat berfungsi, tiga komponen utama di bawah ini wajib tersedia secara lengkap.

A. Komponen Utama Sistem Komputer (Hardware, Software, Brainware)

Komponen Sub-Kategori Contoh Nyata Peran Utama
Software
(Perangkat Lunak)		 Sistem Operasi, Aplikasi, Bahasa Pemrograman, Program Utilitas Windows 11, Android, MS Word, Chrome, Python, Scratch, WinRAR, Antivirus Menjadi jembatan antara pengguna dan perangkat keras serta menjalankan tugas spesifik.
Brainware
(Pengguna / SDM)		 Operator (End User), Programmer, System Analyst, Administrator & Teknisi Siswa pengetik tugas, pembuat aplikasi web, perancang sistem, teknisi jaringan Memberi perintah, mengolah informasi, dan memelihara kinerja komputer.

B. Klasifikasi Lengkap Perangkat Keras (Hardware) & Visual Ikon

Berdasarkan fungsi kerjanya dalam alur pengolahan data, perangkat keras (hardware) dibagi menjadi 4 kelompok utama. Klik tombol filter kategori di bawah ini untuk melihat seluruh daftar perangkat beserta visualnya!

EKSPLORATOR KLASIFIKASI PERANGKAT KERAS (KLIK KATEGORI)
Perbandingan Penting Perangkat Keras yang Sering Muncul di Ujian:

• RAM vs ROM: RAM bersifat sementara (volatile — data hilang saat listrik mati), menyimpan aplikasi yang sedang aktif berjalan. ROM bersifat permanen (non-volatile), menyimpan program dasar BIOS/UEFI saat komputer pertama dinyalakan.

• HDD vs SSD: HDD menggunakan piringan cakram magnetik yang berputar mekanis, sedangkan SSD menggunakan chip memori flash elektronik sehingga kecepatan baca/tulis jauh lebih tinggi dan tahan guncangan.

• Scanner vs Printer: Scanner termasuk Input Device (mengubah dokumen kertas menjadi gambar digital), sedangkan Printer termasuk Output Device (mencetak file digital menjadi kertas fisik).

C. Alur Operasi CPU (Machine Cycle: Fetch – Decode – Execute – Store)

Di dalam CPU (Central Processing Unit) terdapat dua unit inti: Control Unit (CU) sebagai pengatur lalu lintas instruksi dan ALU (Arithmetic Logic Unit) sebagai unit pelaksana perhitungan matematika dan perbandingan logika. Setiap satu instruksi diproses melalui 4 tahapan berulang yang disebut Siklus Mesin (Machine Cycle).
