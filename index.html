2B. Mengenal Ekstensi File (File Extension)

Ekstensi file adalah 3 hingga 4 huruf di belakang tanda titik (.) pada nama file yang memberi tahu sistem operasi jenis data tersebut dan aplikasi apa yang tepat untuk membukanya.

⚠️ Catatan Penting: Mengubah nama ekstensi secara manual (misalnya mengubah video.mp4 menjadi video.pdf) tidak mengubah isi struktur data biner asli di dalam file tersebut, sehingga file akan gagal dibuka (corrupted).

3A. Komponen Sistem Komputer (Hardware, Software, Brainware)

Sebuah komputer hanya dapat bekerja dan menghasilkan informasi jika ketiga unsur utama di bawah ini saling terhubung dan bekerja sama:

🖥️ 1. HARDWARE (Perangkat Keras)

Komponen fisik komputer yang berwujud nyata, dapat dilihat, dan disentuh.

Kategori: Input, Process, Output, Storage Device.

⇄
💿 2. SOFTWARE (Perangkat Lunak)

Program atau instruksi digital tidak berwujud fisik yang mengendalikan hardware.

  • Sistem Operasi: Windows, macOS, Linux, Android, iOS.
  • Aplikasi: MS Word, Excel, Chrome, Canva, WhatsApp.
  • Pemrograman: Python, Scratch, C++, VS Code.
  • Utilitas: Antivirus, WinRAR, Disk Cleanup.
⇄
🧑‍💻 3. BRAINWARE (Pengguna / SDM)

Manusia yang mengoperasikan, merancang, dan merawat sistem komputer.

  • Operator / End User: Siswa, kasir, staf kantor.
  • Programmer: Pembuat kode aplikasi/web.
  • System Analyst: Perancang alur sistem.
  • Admin & Teknisi: Pengelola jaringan & perakit PC.

3B. Klasifikasi Lengkap Perangkat Keras (Hardware)

Pilih kategori perangkat keras di bawah ini untuk melihat seluruh contoh perangkat beserta kegunaannya:

🔍 Perbedaan Penting yang Sering Diujikan:
• RAM vs ROM: RAM bersifat sementara (volatile — data hilang saat listrik mati), sedangkan ROM bersifat permanen (non-volatile — menyimpan firmware BIOS/UEFI).
• HDD vs SSD: HDD memakai piringan cakram berputar, sedangkan SSD memakai chip memori flash (jauh lebih cepat, hening, dan tahan guncangan).
• Scanner vs Printer: Scanner adalah Input (kertas → file digital), sedangkan Printer adalah Output (file digital → cetakan kertas).

3C. Simulasi Bergerak: Alur Operasi CPU (Machine Cycle)

Di dalam CPU terdapat Control Unit (CU) sebagai pengatur instruksi dan ALU (Arithmetic Logic Unit) sebagai penghitung matematika/logika. Klik tombol di bawah untuk melihat simulasi CPU memproses perintah 10 x 2:

🧠 ARSITEKTUR PEMROSESAN CPU (MACHINE CYCLE) Input Pengguna: Menghitung 10 × 2
1. FETCH (Ambil)
📥

Control Unit (CU) mengambil instruksi 10 × 2 dari memori utama (RAM).

2. DECODE (Terjemahkan)
🔍

Control Unit (CU) menerjemahkan simbol × sebagai perintah perkalian angka 10 dan 2.

3. EXECUTE (Eksekusi)
⚡

ALU menjalankan perhitungan matematika: 10 × 2 = 20.

4. STORE (Simpan)
💾

Hasil angka 20 disimpan ke Register/RAM lalu dikirim ke layar monitor.

> Status CPU: Siap menerima instruksi. Klik tombol "Jalankan Simulasi Siklus CPU" di atas.
